About the Project

About SiteSpy

SiteSpy is a mobile-first construction project records and cost estimation app built with Expo React Native, Firebase, and Firestore. It helps construction teams capture measurements, estimate material costs, and review project history on any device — even in low-connectivity field conditions.

My Contribution

My Contribution

I designed and built the authentication screen layer that every SiteSpy user passes through. LoginScreen.js handles sign-in with validation and clear error messaging. RegisterScreen.js guides new users through account creation with field validation and password confirmation. ForgotPasswordScreen.js provides a clean recovery flow.
