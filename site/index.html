About the Project

About SiteSpy

SiteSpy is a mobile-first construction project records and cost estimation app built with Expo React Native, Firebase, and Firestore. It helps construction teams capture measurements, estimate material costs, organise site records, and review project history on any device — even in low-connectivity field conditions.

My Contribution

My Contribution

I designed and built the authentication screen layer that every SiteSpy user passes through. LoginScreen.js handles sign-in with validation and clear error messaging. RegisterScreen.js guides new users through account creation with field validation and password confirmation. ForgotPasswordScreen.js provides a clean recovery flow. All three screens connect to authService.js and present consistent visual feedback so users always know what the app expects from them.

Reflection

My Reflection

Authentication is the first thing users experience, so it sets the tone. I learned to design screens that handle bad input gracefully without making users feel blamed. The password recovery flow was the most nuanced — users often reach it when frustrated, so the design had to be extra clear and reassuring. Visual consistency across all three screens required careful component sharing.
